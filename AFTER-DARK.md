# Juice Shop After Dark

A training fork of [OWASP Juice Shop](https://github.com/juice-shop/juice-shop) v20.4.0 for the **Field Agents** CTF (mission S1-K8, After Dark).

- The first commit (tag `upstream-v20.4.0`) is upstream Juice Shop, unmodified except that `.github/` is left out.
- Later commits add new features to the shop. Some of them contain original, deliberately planted vulnerabilities. Finding and proving them is the mission. The bug list and solutions are not in this repo.
- Run it only in the Field Agents Codespace. It is intentionally insecure: never expose it to a network.
